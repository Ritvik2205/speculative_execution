## Notes

1. Best fit for a verifiable vulnerable/mitigated pair: source 4 (`git log -S`) joined to source 3 (nluedtke CVE-to-commit map) and source 5 (smatch) as a candidate filter. This gives per-commit ground truth without a third-party label.
2. Kasper and InSpectre are the strongest academic provenance (peer-reviewed, named tools). InSpectre has a released, Apache-2.0 pipeline and counts, but its outputs are gadgets at a single kernel version, not commit pairs. Kasper's gadget list was not found publicly; ask the authors before citing counts as data.
3. The smatch output is a candidate generator with a high false-positive rate. Any label derived from it needs a manual or oracle pass before it counts as ground truth.
4. Licences: kernel patches are GPL-2.0, which permits reuse of diffs for research. Verify the Kasper code licence on the repo itself; the 404 means the secondary-source claim is unconfirmed.
5. Reproducibility: pin every pair to a commit SHA and kernel version. Record the `git` commands and the upstream SHA for each row in any dataset manifest.
6. Several CVE-to-commit links in the mirrors above carry stable-backport tags; always take the mainline SHA, not a backport.

## Top 5 by value (summary)

1. `git log -S array_index_nospec` on a local torvalds/linux clone, joined to the CVE map: the largest source of genuine before/after pairs.
2. nluedtke/linux_kernel_cves: CVE-to-fixing-commit mapping, Apache-2.0, archived 2024.
3. InSpectre Gadget (vusec, USENIX Sec 2024): Apache-2.0 pipeline, 1,511 exploitable gadgets at 6.6-rc4.
4. Kasper (NDSS 2022): 1,379 gadgets, peer-reviewed, but no public list located.
5. smatch Spectre v1 check: candidate generator, about 800 initial sites, needs labelling.

Items not verified in this pass: vulns.git and linux-cve-announce (403); Kasper GitHub repo (404); individual CVE pages (NVD fetch returned an empty page).
