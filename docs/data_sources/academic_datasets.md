# Academic Spectre-gadget benchmarks and datasets: catalogue

Scope: publicly released artifacts that other papers evaluate on. Catalogue only; nothing downloaded. "Verified" means the URL was fetched or returned by search on 2026-11-05. Items marked UNVERIFIED were not confirmed and need a manual check.

Label-type key:
- **HW** = hardware-confirmed
- **TOOL** = tool-confirmed (analyser verdict, not hand-checked)
- **HAND** = hand-labelled / by construction (planted or known-pattern)
- **NONE** = no per-program ground truth released

## Notes

1. **The most reviewer-recognised set is Kocher's 15 variants**, mirrored in Spectector (#1), Pitchfork (#3) and KLEESpectre/oo7. This is the de facto Spectre v1 benchmark, but it is HAND-labelled by construction and is coarse: 15 programs, one class (SPECTRE_V1). It works as a sanity check, not as a ground-truth eval set.
2. **No public corpus in this list is hardware-confirmed except as a per-program claim** (RETBleed, Revizor, Kasper PoC). Those are the only route to HW-grade labels, and they are not packaged as labelled gadget sets.
3. **FastSpec (#15) is the only large labelled-by-generator dataset found.** It is Spectre-V1 only and its labels come from the generator, so it is circular for a detector paper. Treat it as pretraining or a baseline, not ground truth.
4. **Most tools ship code, not labelled gadget corpora.** For an evaluation set, the usable items are the test programs and their expected results (Spectector, Pitchfork `kocher_analysis.txt`, Haunted litmus tests). These can be relabelled by running a fixed oracle.
5. **Class coverage gap.** Across all verified items, labelled material covers SPECTRE_V1 (Kocher, FastSpec), SPECTRE_V4 (Haunted litmus-STL, Pitchfork's v1.1 set), and generic transient-execution HW PoCs (RETBleed, Revizor). **INCEPTION, BHI and L1TF have no verified labelled public corpus** in this pass. MDS has only the Revizor HW violations.
6. **ISA.** Almost everything is x86. ARM64 and RISC-V labelled public data was not found in this pass.
7. **Licence.** Several licences were not confirmed on the page. Check each LICENSE file before redistributing; do not assume permissive terms.
8. **Staleness.** SpecFuzz was archived 2026-01-16 and is read-only. Teapot, SpecTaint and SpecuSym have no verified code.
9. **Next steps for the paper.** (a) Clone #1 and #3 and check their expected-results files against Spectector and Pitchfork. (b) Ask the authors of Haunted, Teapot and Phantom for artifact links, since no repo was located. (c) Run a search on the BHI, Inception and Retbleed artifact appendices for labelled PoC sets.
