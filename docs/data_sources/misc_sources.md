## Notes

1. Only one source (InSpectre Gadget) shows a real per-gadget label set, and it is generated by the user rather than shipped. The release-tag result data (v0.1, v1.0) still needs a direct check against the release assets before use. Counts quoted above come from one search snippet.
2. Revizor is the strongest hardware-ground-truth candidate because its violation artifacts are self-describing and reproducible. No published corpus was found on the repository page, so this still needs an issue or release search.
3. Most named corpora (Kasper, Phantom, SpecDoctor, Transynther, Osiris, OSWALD, transient-fail) returned 404 or were not found. The URLs were guessed, not confirmed, so the repos may exist under other names. Confirm with a web search before citing any of them.
4. The NVD API query returned zero results, which conflicts with the aggregator data. Do not treat it as a count of CWE-1342 CVEs.
5. The following were not searched in this pass: Semgrep, Clang static analyzer, BHI gadget papers, Kasper paper artifacts, GHSA queries with a token.
6. Licence entries marked V were read from the repo page. Confirm them against the LICENSE file before any redistribution.
